Native OAuth and streaming protocol adapted from [pi-antigravity](https://github.com/Rahularya01/pi-antigravity), version 0.10.0, commit `d59d22b`.

This port uses AkramCode's provider registration, credential storage, transcript, tools and event stream. It omits upstream account files, account rotation, search tools and image-generation tools. It discovers the account's chat model catalog without adding static model aliases.
