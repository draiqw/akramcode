# akramcode

AI coding assistant for the terminal.

## Install

```sh
curl -fsSL https://github.com/draiqw/akramcode/releases/latest/download/install.sh | sh
```

Update an existing install with `akramcode update --self`.

Builds for macOS and Linux (arm64, x64) are attached to each [release](https://github.com/draiqw/akramcode/releases). This repository holds releases only; akramcode is proprietary software, see [LICENSE](LICENSE).
