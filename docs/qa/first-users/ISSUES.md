# Проблемы первых пользователей (до исправлений)

Первый успешный результат: в своём проекте запустить `akramcode`, подключить модель (`/login`) и получить ответ агента на первую задачу без ошибки.

Персоны: 1 - нетерпеливый, 2 - скептик, 3 - смартфон (46x26, медленный ответ модели), 4 - тестировщик на прочность.
Одинаковые проблемы в одном месте одного экрана/страницы объединены. Сортировка по числу персон.
